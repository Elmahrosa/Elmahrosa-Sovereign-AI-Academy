# ELMAHROSA Sovereign AI Academy — Governance & Documentation

Public, documentation-only home for the Elmahrosa Sovereign AI Academy:
governance, tutorials, workshops, and FAQs for sovereign AI engineering,
council participation, and the TEOS / ERT ecosystem.

**Operating principle:** *Law authorizes → Governance ratifies → Policy
enforces → Code executes. Nothing more.* (القانون فوق الكود)

## What lives here (docs only)

| Path | Content |
|------|---------|
| `docs/governance.md` | Governance overview, security architecture, institutional AI philosophy |
| `docs/COUNCIL_MEMBERSHIP_ONBOARDING.md` | Council membership onboarding reference |

| `workshops/` | Workshop materials (e.g. W-01) |
| `faq/` | Common questions: sovereignty, governance, compliance |
